# run-01 — Alan 本人的真實面試閉環

第一筆（也可能是這輪唯一一筆）真實資料。流程與判準見 [../mvp-plan.md](../mvp-plan.md)。

| 檔案 | 內容 | commit 時機 |
|---|---|---|
| `input-summary.md` | 去識別化的輸入摘要 | Wave 1 |
| `ai-output.md` | 缺口診斷、進階問題 8 題、行動推薦 | **面試前**，證明預測不是事後補的 |
| `commitments.md` | 勾選「我打算做」與面試前一天的「做了沒」 | 面試前 |
| `actual.md` | 面試官實際問的每一題 | **面試後、打開 `ai-output.md` 之前** |
| `review.md` | 命中率、四格回填、對照失敗門檻的判讀 | 比對之後 |

`actual.md` 的 commit 時間戳是這輪防止事後合理化的唯一機制，
順序不能顛倒。
