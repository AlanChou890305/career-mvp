# 用詞統一表

三個人講同一件事時用同一個詞，避免討論時對不上。

---

## 編碼系統

推演過程中痛點原型與利基點都用了 A–E 字母，容易混淆。這裡分開：

| 對象 | 編碼方式 | 範例 |
|---|---|---|
| 痛點原型 | 單一大寫字母 A–I | `C 能力存疑` |
| 利基點／象限 | N + 數字 | `N16`、`N19` |
| 旅程階段 | 圈碼數字 ①–⑥ | `③ 確認能力適配` |
| 解法 | # + 數字 | `#2 履歷經歷分析` |
| Persona | 英文名 | `Emily`、`Chris` |

## 痛點原型 A–I

| 代號 | 名稱 |
|---|---|
| A | 方向真空 |
| B | 選項過載 |
| C | 能力存疑 |
| D | 動機真空 |
| E | 驗證信心不足 |
| F | 決策反覆 |
| G | 價值拉扯 |
| H | 外在期待 |
| I | 瓶頸評估 |

另有「急於找機會者」，是行為模式不是痛點原型，不給代號。

## 名詞

| 詞 | 意思 |
|---|---|
| **CDDQ** | Career Decision-making Difficulties Questionnaire。把職涯決策困難分成缺乏準備／缺乏資訊／資訊不一致三大類的學術框架 |
| **白地** | 24 組象限中沒有競品佔據、且我方定位落得進去的格子 |
| **擁擠** | 該象限已有競品佔據我方定位附近 |
| **進階問題** | AI 讀完使用者背景與 JD 後追問的問題。核心功能之一 |
| **行動推薦** | AI 給的準備建議。核心功能之一 |
| **適配度判斷** | AI 評估此人與 JD 的契合程度。這次是觀察值，不是驗證指標 |
| **語料 / fixtures** | 蒐集來的公開面試心得，放在 `assets/fixtures/`。三支分支共用同一批 |
| **命中率** | AI 預測的進階問題中，語意上對應到面試官實際問題的比例 |
| **採用率** | AI 給的行動推薦中，使用者真的照做且派上用場的比例 |
