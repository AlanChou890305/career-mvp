# 第二批語料（7 篇）的預測摘要

第一批 3 篇的完整逐題紀錄在同資料夾的個別檔案裡。這 7 篇為節省篇幅只記摘要與命中判定，完整的每題內容（question / source_phrase / prep_note / hit）都存在 `../../webapp/data.js` 對應 persona 的 `predictions` 陣列裡，是同一份資料，這裡不重複貼一次。

## pr-hr_recruiter-01（人資招募）
命中率低（0 強、1 弱 / 8）。真實問題是價值觀取捨與招募策略發想的開放題（例如「為公司賺錢 vs. 員工權益，你怎麼選」），這版 prompt 抓的是背景/JD 證據缺口，兩者本質不同類型的追問。

## pharma-sales_rep-01（醫藥業務）
命中率中等（2 強、3 弱 / 8）。「陌生開發意願」與「研究轉業務的動機」被準確預測到，這是背景與 JD 之間最大、最明顯的落差。

## nonprofit-social_worker-01（社工員）
命中率中等偏低（0 強、3 弱 / 8）。背景資訊極簡（只有一句話），這版 prompt 猜到會有法規類筆試與上機測驗，但猜不到具體內容——背景太薄時，這版 prompt 的「猜形式不猜內容」限制特別明顯。

## tech-frontend_engineer-01（前端工程師）
命中率幾乎零（0 強、0 弱 / 8）。真實面試是標準化技術知識題（JS/React/CSS/演算法），跟候選人背景敘述無關——跟 fintech-data_scientist-01 同一種「技術篩選題測不到」模式。

## telecom-accounting_manager-01（會計管理師）
命中率中等（1 強、1 弱 / 8）。「為什麼選電信業、做過什麼功課」被準確預測到，對應到面試官最尖銳的兩題。技術性追問（IFRS15、稅務）完全沒被問到——這場面試官全程聚焦動機與公司認知。

## retail-management_trainee-01（零售儲備幹部）
命中率最高（2 強、2 弱 / 8）。真實面試幾乎全繞著「碩士學歷 vs. 基層零售工作」的落差追問，正中這版 prompt 的設計核心。唯一漏網之魚：「你不會日文」——一個語言能力缺口，這版 prompt 沒有主動查證 JD 或背景裡的語言要求。

## hospitality-front_desk-01（飯店前台）
命中率中等（1 強、1 弱 / 8）。「大夜班接受度」被準確預測到。「這家飯店缺點是什麼」這種考驗有沒有做功課的題型完全沒被預測到——這類題不是背景/JD 缺口能推論出來的，需要額外的公司資訊輸入。
