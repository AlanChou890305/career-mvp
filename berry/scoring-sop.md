# 計分 SOP

跑實驗、算命中率的統一做法。6 筆一起跑時照這個，之後收斂日才比得起來。

由來：試跑 tech-pm-01、tech-pm-03 後發現——(1) 標準答案籠統的語料命中率會虛高；(2) 同一筆用不同判準會從 50% 變 88%。所以計分要標準化。

---

## 一、什麼算「命中」

- **語意相同即命中，不要求字面一致**（照 validation-plan.md）。
- 判定分三級，每題標一個：
  - ✅ **命中**：AI 問的和面試官問的，語意上是同一題
  - 🔶 **部分**：AI 摸到主題但沒摸到精準角度（例：AI 問「怎麼管 KPI」，實際問「KPI 的制定標準」）
  - ❌ **沒中**：AI 完全沒預測到

## 二、雙軌記錄（關鍵）

每筆都記兩個數字，因為「部分算不算命中」會大幅改變結果：

- **寬鬆命中率** = (✅ + 🔶) / 實際題數
- **嚴格命中率** = ✅ / 實際題數

兩個都報。三人一起看時，用同一軌比較。

## 三、★ 經歷題分開算

- 通用題（自我介紹、Leetcode、離職動機）AI 看職位就能猜，會灌水總命中率。
- 所以另外算一條：**★ 經歷題命中率** = ★ 題命中數 / ★ 題總數。
- **這條才是 N16 的真實水準**，收斂日重點看這個。

## 四、判準爭議記下來

判 🔶 還是 ✅ 常有爭議（例：「處理績效差的人」算不算命中「PIP 執行流程」？）。
- 有爭議的當下**別糾結**，標記下來繼續跑。
- 全部記進每筆的「爭議」欄，**收斂日三人一起裁決**——這是 pilot 對齊判準的核心動作。

## 五、每筆的記錄格式

跑完一筆，在該 fixture 檔案末端或另開結果檔記：

```
### 結果（prompt vX）
- 實際題數：8　★題數：2
- ✅ 命中：4　🔶 部分：3　❌ 沒中：1
- 寬鬆命中率：88%　嚴格命中率：50%
- ★ 經歷題命中：0.5 / 2（都只到部分）
- 爭議：Q2「處理績效差的人」是否命中「PIP 執行流程」？→ 待收斂日
```

## 六、收斂日要報的三個數字

1. 6 筆的**平均寬鬆 / 嚴格命中率**（各一條）
2. **★ 經歷題命中率**（含金量最高）
3. 判準爭議清單 + 我做了什麼 prompt 取捨、為什麼

排序比高下用「嚴格命中率」和「★ 經歷題命中率」，不用寬鬆的（會被通用題灌水）。
