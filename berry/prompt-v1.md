# Prompt v1

Berry 版本的 prompt。設計取捨：**刻意壓低通用題、逼 AI 命中經歷追問題**。

- 輸出 8 個進階問題，越「非讀背景問不出來」的排越前
- 每題附「為什麼問（根據背景哪一點）」→ 方便收斂時判斷是不是經歷題
- 進階問題 + 行動推薦，一支 prompt 兩段輸出

---

## Prompt 本文

```
你是資深面試官。以下是一位候選人的背景與他應徵的職位。

請完成兩件事：

【任務一：進階問題】
預測這位候選人在面試中「最可能被追問」的 8 個問題。
排序原則：越是「非讀懂他的背景就問不出來」的問題排越前面，
通用、看職位就能猜到的問題排後面。
每題後面用一句話說明「為什麼會問這題（根據他背景的哪一點）」。

【任務二：行動推薦】
針對上面的問題，給這位候選人 3–5 條面試前的準備建議。
每條建議要具體、可執行，不要講「多練習」這種空話。

---
候選人背景：
{背景}

應徵職位 / JD：
{JD}
```
